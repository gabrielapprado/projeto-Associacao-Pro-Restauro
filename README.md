
  # APRI_SITE_V3

  This is a code bundle for APRI_SITE_V3. The original project is available at https://www.figma.com/design/ZYuursbdeHA2rmajCoAcmK/APRI_SITE_V3.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
  
## Estilos

Os estilos das páginas e dos componentes ficam nos arquivos `*.module.css` ao lado de cada componente, importados como `styles`. O projeto usa CSS nativo, sem Tailwind.

`src/styles/theme.css` centraliza as cores, a tipografia e os tokens compartilhados; `src/styles/globals.css` contém o reset, os estilos base e as animações globais. `src/styles/index.css` carrega esses arquivos e as fontes antes dos componentes.
